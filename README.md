eaglesnest-hoa.net
==================

The public website for https://eaglesnest-hoa.net.

## Development

Requires [mise](https://mise.jdx.dev), which installs the pinned Ruby version.

```sh
mise install        # install Ruby
mise run serve      # serve locally at http://127.0.0.1:4000 with live reload
mise run build      # build the site into _site
mise run check      # check the site configuration for problems
mise run clean      # remove generated site and caches
```

Run `mise tasks` to list all tasks.
